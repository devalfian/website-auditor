# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Contributor Covenant is licensed under CC BY 4.0; the canonical document is maintained by the Contributor Covenant project, so this repository links to it rather than restating it and risking drift.

## In short

Participants are expected to be respectful, to assume good faith, to give and accept constructive feedback, and to keep discussion focused on the work. Harassment, personal attacks, discriminatory language and sustained disruption are not acceptable.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and when representing the project in public.

## Reporting and enforcement

Report concerns through **GitHub private vulnerability reporting** on this repository (Security tab → "Report a vulnerability"), which reaches the maintainer privately. Reports are reviewed and handled as promptly as the maintainer can manage; see the enforcement guidelines in the Contributor Covenant for the range of responses.

No dedicated conduct email address exists; do not assume one does.
